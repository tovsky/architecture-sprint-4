Внедрения кеширования для сервисов позволит:
- повысить производительность систем
- уменьшение нагрузки на БД и сервера
- более быстрый UI для пользователей
- уменьшение затрат на хранилища основных БД
- увеличение кол-ва RPC в системах

Кеширование внедряем в API системах для запросов по заказам
- shop api
- mes api
- crm api

Видится правильным внедрить кеширование для операций чтения информации о заказе (как одного так и коллекций с условиями выборки).
Такое чтение производят как партнеры и пользователи, так и внутренние системы (например дашборд заказов).

При этом максимально важно иметь согласованные данные между кешом и БД, ведь, например один из сценариев работы когда оператор 
должен видеть свежие заказы, кто первый возьмет заказ в работу.

Исходя из логики изложенной выше у нас присутствуют активные операции и чтения, и записи, 
поэтому будем использовать вариацию из двух подход для кеширования: Read-Through и Write-Through.
